# Zapret 2 GUI

Десктопное приложение для обхода блокировок на базе **[zapret](https://github.com/bol-van/zapret)** — окно в стиле Windows 11 и иконка в трее вместо возни с `.bat`-файлами. DPI-логика не переписывается: программа запускает и обслуживает движок `winws2` (bol-van), а сверху даёт удобный интерфейс, диагностику и управление стратегиями.

Написано на C# / .NET 10 (WPF + WPF-UI). Движок и все нужные файлы уже лежат в репозитории — достаточно собрать и запустить.

## Возможности

- Подключение и отключение в один клик, выбор стратегии из списка.
- **Авто-подбор** — перебирает стратегии и оставляет ту, через которую сайты открываются.
- **Диагностика** — таблица доступности (HTTP · TLS 1.2 · TLS 1.3 · пинг) по ключевым сайтам, проверка конфликтующих служб и окружения, прогон стратегий по очереди.
- Редактор стратегий (полная команда `winws2`) и менеджер списков (`lists/*.txt`).
- Сворачивание в трей, автозапуск с Windows, выбор темы, акцента и шрифта.

## Технологии

- **.NET 10**, C#, **WPF** + [WPF-UI](https://github.com/lepoco/wpfui) (Fluent-тема Windows 11), [Hardcodet.NotifyIcon.Wpf](https://github.com/hardcodet/wpf-notifyicon) (трей).
- Движок: **winws2** (zapret v2) + **WinDivert** (перехват пакетов).

## Структура

```
├─ src/Zapret.Core/    логика: обёртка движка, модель стратегий, состояние (net10.0)
├─ src/Zapret.App/     интерфейс: WPF-окно и трей (net10.0-windows)
├─ sample-state/       стратегии и настройки по умолчанию
├─ bin/ lua/ lists/    движок zapret (winws2, WinDivert, Lua-скрипты, списки)
├─ Zapret.slnx         решение из двух проектов
├─ Directory.Build.props    общие настройки сборки
└─ build.bat           сборка 
```

Код разделён на **Zapret.Core** (без интерфейса — вся логика) и **Zapret.App** (интерфейс). Папки `bin/ lua/ lists/` — это внешний движок zapret, а не код обёртки.

## Сборка

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
build.bat            # обычная сборка (нужен .NET 10 Desktop Runtime)
build.bat portable   # автономная, без пререквизитов
```

`build.bat` собирает `Zapret.exe` и складывает его вместе с движком в папку `dist/`. Для разработки достаточно `dotnet build -c Release`.

## Запуск

Запустите `dist/Zapret.exe` **от имени администратора** — права нужны драйверу WinDivert (появится запрос UAC). Докачивать ничего не надо: движок и списки уже в комплекте. Стратегии и настройки создаются в `state/` рядом с exe при первом запуске.

## Как устроен код

**Zapret.Core** — логика без интерфейса:

- `AppPaths` — где что лежит (движок, списки, состояние); ищет корень по `ZAPRET_ROOT`.
- `Models`, `AppState` — модель стратегии и настроек, чтение и запись в JSON.
- `CommandParser`, `CommandBuilder` — превращают команду стратегии в аргументы запуска `winws2`.
- `WinwsRunner` — жизненный цикл движка: снять прежние процессы, запустить, ловить вывод в журнал, убрать драйвер при остановке.
- `AutoPicker` — авто-подбор стратегии (запуск + проверка доступности сайтов).
- `Autostart`, `Lists`, `ListsManager` — автозапуск через планировщик и работа со списками.

**Zapret.App** — интерфейс:

- `MainWindow` — главное окно: боковое меню (Главная / Списки / Редактор / Журнал / Диагностика / Настройки), кнопка подключения, выбор стратегии, авто-подбор, редактор и менеджер списков.
- `Diagnostics` — проверки окружения и конфликтов плюс тесты доступности сайтов.
- `App` — единственный экземпляр приложения, иконка в трее, сворачивание, экономия памяти.

## Обратная связь

Проблемы интерфейса, запуска движка или стратегий — в issues. Если **сайт не открывается или стратегия не работает**, приложите:

- таблицу диагностики (вкладка «Диагностика» → «Проверить»);
- провайдера и регион, версию Windows;
- выбранную стратегию и лог из вкладки «Журнал».

Проблемы самой DPI-логики движка — в [bol-van/zapret](https://github.com/bol-van/zapret).
